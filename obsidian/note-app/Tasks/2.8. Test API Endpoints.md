

# Test API Endpoints

## Prerequisites
- Backend server configured (reference: `2.2. Set Up FastAPI Application`)
- Database setup completed
- Authentication implemented
- CRUD operations for notes implemented

## Steps

### 1. Start the Application
- [x] Open terminal and navigate to backend directory:
  ```bash
  cd backend
  ```
- [x] Activate virtual environment:
  ```bash
  source venv/bin/activate  # For Unix/macOS
  # or
  .\venv\Scripts\activate  # For Windows
  ```
- [x] Start the server:
  ```bash
  uvicorn app.main:app --reload
  ```
- [x] Verify server is running at http://localhost:8000

### 2. Access Swagger UI Documentation
- [x] Open browser and navigate to http://localhost:8000/docs
- [x] Verify all endpoints are listed:
  - Authentication endpoints (`/auth/register`, `/auth/token`)
  - Notes endpoints (`/notes/`)

### 3. Test Authentication Endpoints
- [x] Test user registration:
  1. Find POST `/auth/register` endpoint
  2. Click "Try it out"
  3. Input test user data:
     ```json
     {
       "email": "test@example.com",
       "password": "testpassword123"
     }
     ```
  4. Execute and verify 200 response

- [x] Test user login:
  1. Find POST `/auth/token` endpoint
  2. Click "Try it out"
  3. Input credentials:
     - username: test@example.com
     - password: testpassword123
  4. Execute and verify token response

### 4. Test Notes Endpoints
- [x] Authorize in Swagger UI:
  1. Click "Authorize" button at the top
  2. Enter token: `Bearer <your_access_token>`

- [x] Test note creation (POST `/notes/`):
  ```json
  {
    "title": "Test Note",
    "content": "This is a test note content"
  }
  ```

- [x] Test note retrieval:
  1. GET `/notes/` (list all notes)
  2. GET `/notes/{note_id}` (get specific note)

- [x] Test note update (PUT `/notes/{note_id}`):
  ```json
  {
    "title": "Updated Test Note",
    "content": "This is updated content"
  }
  ```

- [x] Test note deletion (DELETE `/notes/{note_id}`)

### 5. Verification Checklist
- [x] All endpoints return expected status codes
- [x] Authentication is working properly
- [x] CRUD operations function correctly
- [x] Error responses are handled appropriately
